To-Do List Web Application

A responsive and user-friendly To-Do List web application built using HTML, CSS, and JavaScript. This application helps users efficiently manage their daily tasks by allowing them to add, edit, mark as completed, and delete tasks. The clean and modern interface provides a smooth user experience across desktop and mobile devices.

Key Features
Add new tasks instantly
Mark tasks as completed
Edit existing tasks
Delete tasks easily
Responsive design for all screen sizes
Clean and modern UI
Dynamic task management using JavaScript
Local storage support to save tasks permanently
Technologies Used
HTML5
CSS3
JavaScript (ES6)
Local Storage API
Purpose

This project demonstrates fundamental front-end web development skills, including DOM manipulation, event handling, responsive design, and client-side data storage.
